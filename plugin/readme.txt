Manage Podcasting 2.0 feeds and files.

== Description ==

Podcasting 2.0 apps are the target. Apple Podcasts, Spotify and similar services are not Podcasting 2.0 compliant, so they are only secondary accommodations: where they need something extra (for example JPEG or PNG show art) you get a warning, not a block.

Early skeleton. Add the shortcode `[podpublisher]` to a page. Features are not built yet.

== Installation ==

1. Upload the plugin folder to wp-content/plugins and activate it.
2. Add `[podpublisher]` to a page.
